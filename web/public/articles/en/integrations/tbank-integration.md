### Setup guide

1. Open T-Bank Invest settings and create an API token.
2. Start with **Sandbox** environment for testing and use a sandbox token.
3. Paste the token, choose environment, optionally set default account, then click **Save and connect**.
4. If needed, update your default account and save it.
5. Use ticker lookup in the trading workspace to resolve instrument id (UID/FIGI) from MOEX ticker.
6. Do not mix sandbox token with production environment.
