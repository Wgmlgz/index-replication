### Setup guide (Sandbox)

1. Open [T-Bank Invest api settings](https://www.tbank.ru/invest/settings/api/)
2. Click **Выпустить токен** under **Создание токена для песочницы**
3. On new opened page copy token by clicking **Скопировать токен**
4. Paste the token in the form below, then click **Save and connect**
5. Done!
