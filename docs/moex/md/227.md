# /iss/turnovers

Get current turnover on all the markets.
Example: https://iss.moex.com/iss/turnovers.xml?lang=en

turnovers (GET)

Market turnovers

## Arguments

- `lang` — Language of the result set: ru or en, default: ru, type: var
- `is_tonight_session` — default: 0, type: var
- `date` — default: today, type: var

turnoversprevdate (GET)

Market turnovers of previous trading day
## Arguments

- `lang` — default: ru, type: var
- `is_tonight_session` — default: 0, type: var
- `date` — default: today, type: var
