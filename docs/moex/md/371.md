# /iss/engines/[engine]/markets/[market]/boards/[board]/securities/[security]/orderbook

Get the best quotes for the specified security on the specified board.

orderbook (GET)

List of best quotes

## Arguments

- `start` — Row number (the number of the first row is 0) to begin the result set with (see developer manual). If the result set contains no data then the specified number is greater than the total number of rows available., default: 0, type: number
- `seqnum` — (Deprecated) Update sequence number. Incremental parameter which can be used to request only updates., default: —, type: number
- `securities` — Security filter. For example: securities=GAZP,AFLT,LKOH, default: —, type: var

dataversion (GET)

Data version information.
