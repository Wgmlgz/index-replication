# /iss/engines/[engine]/markets/[market]/.*?securities/columns

Get the description of columns in requests for securities.
Example: https://iss.moex.com/iss/engines/stock/markets/shares/securities/columns.xml?lang=en

securities (GET)

Fields in table with static security data

## Arguments

- `lang` — Language of the result set: ru or en, default: ru, type: var

marketdata (GET)

Fields in tables with market data
## Arguments

- `lang` — Language of the result set: ru or en, default: ru, type: var

marketdata_yields (GET)

## Arguments

- `lang` — default: ru, type: var
