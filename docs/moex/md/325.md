# /iss/engines/[engine]/markets/[market]/boards/[board]/trades

Get all trades from the specified board.

trades (GET)

List of trades

## Arguments

- `tradeno` — Trade number to begin the result set with. Data returns included trades starting from recevied tradeno parameter. If you need to receve data starting next tradeno - use option "next_trade=1". Deals returns on time ordered mode. On FORTS deals number (TRADENO) of latest deal can be less then previous., default: 0, type: var
- `recno` — FORTS and OPTIONS markets only. Filter via RECNO field (number in deals order). Replaces filter "tradeno". If you need to receve data starting next tradeno - use option "next_trade=1"., default: 0, type: var
- `next_trade` — Exclude received tradeno filter to this result., default: 0, type: var
- `securities` — No descr_eniption available., default: —, type: var
- `limit` — default: 5000, type: var
- `reversed` — default: 0, type: var
- `previous_session` — default: 0, type: var
- `start` — Row number (the number of the first row is 0) to begin the result set with (see developer manual). If the result set contains no data then the specified number is greater than the total number of rows available., default: 0, type: number
