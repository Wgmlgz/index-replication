# /iss/history/engines/[engine]/markets/[market]/boardgroups/[boardgroup]/dates

Get dates for which history for the specified board group is available.

dates (GET)

Date intervals available in the history.

## Arguments

- `interim` — Show intermediate trading dates (currency market only), default: 0, type: var
- `tradingsession` — Show data for required session (Stock market only) 0 - Morning 1 - Main 2 - Evening 3 - Total, default: —, type: var
