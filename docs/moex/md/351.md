# /iss/engines/[engine]/markets/[market]

Get the list of boards, board groups and metadata for all the table fields returned by other requests.
Example: https://iss.moex.com/iss/engines/stock/markets/shares.xml?lang=en

boards (GET)

Boards available on the market

## Arguments

- `lang` — Language of the result set: ru or en, default: ru, type: var

boardgroups (GET)

Board groups
## Arguments

- `lang` — Language of the result set: ru or en, default: ru, type: var

securities (GET)

Fields in table with static security data
## Arguments

- `lang` — Language of the result set: ru or en, default: ru, type: var

marketdata (GET)

Fields in tables with market data
## Arguments

- `lang` — Language of the result set: ru or en, default: ru, type: var

trades (GET)

Fields for table with trades
## Arguments

- `lang` — Language of the result set: ru or en, default: ru, type: var

orderbook (GET)

Fields for orderbooks.
## Arguments

- `lang` — Language of the result set: ru or en, default: ru, type: var

history (GET)

Fields in tables with history.
## Arguments

- `lang` — Language of the result set: ru or en, default: ru, type: var

trades_hist (GET)

Fields for table with history trades
## Arguments

- `lang` — Language of the result set: ru or en, default: ru, type: var

marketdata_yields (GET)

## Arguments

- `lang` — default: ru, type: var

trades_yields (GET)

## Arguments

- `lang` — default: ru, type: var

history_yields (GET)

## Arguments

- `lang` — default: ru, type: var

secstats (GET)

## Arguments

- `lang` — default: ru, type: var
