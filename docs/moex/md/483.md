# /iss/history/engines/[engine]/markets/[market]/boardgroups/[boardgroup]/securities/[security]

Get trade results for the specified security on the specified board group for the specified date.

history (GET)

Trade results for the specified security on the specified board, filtered by date interval.

## Arguments

- `sort_order` — Sort order direction., default: TRADEDATE, type: var
- `sort_order_desc` — (deprecated) Sort order. Can be empty or set to 'DESC', default: —, type: var
- `from` — Interval start date Format: YYYY-MM-DD., default: —, type: var
- `till` — Interval end date Format: YYYY-MM-DD., default: 2037-12-31, type: var
- `numtrades` — Minimum number of trades with a security., default: 0, type: var
- `lang` — Language of the result set: ru or en, default: ru, type: var
- `limit` — default: 100, type: var
- `sort_column` — Field to order the result set by., default: TRADEDATE, type: var
- `start` — Row number (the number of the first row is 0) to begin the result set with (see developer manual). If the result set contains no data then the specified number is greater than the total number of rows available., default: 0, type: number
- `tradingsession` — Show data for required session (Stock market only) 0 - Morning 1 - Main 2 - Evening 3 - Total, default: —, type: var
- `marketprice_board` — default: —, type: var
