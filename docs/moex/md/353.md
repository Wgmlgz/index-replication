# /iss/engines/[engine]/markets/[market]/boards/[board]/securities

Get metadata and market data for the specified security traded on the specified board.
Example: https://iss.moex.com/iss/engines/stock/markets/shares/boards/TQBR/securities.xml?lang=en

securities (GET)

- `primary_board` — default: —, type: var
- `index` — default: —, type: var
- `security_collection` — default: —, type: var
- `previous_session` — default: 0, type: var
- `securities` — default: —, type: var
- `first` — Return n first lines, default: 0, type: var
- `sort_column` — default: —, type: var
- `sort_order` — default: asc, type: var
- `leaders` — default: 0, type: var
- `nearest` — default: 0, type: var
- `assets` — Asset filter (only futures), default: —, type: var
- `sectypes` — Security type filter, default: —, type: var
