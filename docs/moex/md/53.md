# /iss/statistics/engines/stock/currentprices

currentprices (GET)

Stock current prices

## Arguments

- `date` — default: today, type: var
- `start` — default: 0, type: var
- `tradingsession` — Filter by trading avi_api_session: 0 - Morning session 1 - Main session 2 - Evening session 5 - Weekend additional trading session default - show all sessions at once, default: —, type: var
