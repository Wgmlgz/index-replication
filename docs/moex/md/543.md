# /iss/index

Get initial ISS reference.
Example: https://iss.moex.com/iss/index.xml?lang=en

engines (GET)

List of the available Trading Systems

## Arguments

- `lang` — Language of the result set: ru or en, default: ru, type: var

markets (GET)

Available markets and their metadata
## Arguments

- `lang` — Language of the result set: ru or en, default: ru, type: var

boards (GET)

Boards info
## Arguments

- `lang` — Language of the result set: ru or en, default: ru, type: var

boardgroups (GET)

Board groups info
## Arguments

- `lang` — Language of the result set: ru or en, default: ru, type: var
- `engine` — default: —, type: var
- `is_traded` — default: 0, type: var

durations (GET)

List of available intervals for candlestick charts with HLOCV data.
## Arguments

- `lang` — Language of the result set: ru or en, default: ru, type: var

securitytypes (GET)

## Arguments

- `engine` — default: —, type: var
- `lang` — default: ru, type: var

securitygroups (GET)

## Arguments

- `lang` — Language of the result set: ru or en, default: ru, type: var
- `hide_inactive` — default: 0, type: var
- `securitygroups` — default: —, type: var
- `trade_engine` — default: —, type: var

securitycollections (GET)

## Arguments

- `lang` — default: ru, type: var
