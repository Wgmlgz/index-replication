# /iss/history/engines/[engine]/markets/[market]/boards/[board]/securities

Get trade results for all the securities on the specified board for the specified date.

history (GET)

Trade results for all the securities on the specified board, filtered by date.

## Arguments

- `security_collection` — default: —, type: var
- `marketprice_board` — default: —, type: var
- `tradingsession` — Show data for required session (Stock market only) 0 - Morning 1 - Main 2 - Evening 3 - Total, default: —, type: var
- `start` — Row number (the number of the first row is 0) to begin the result set with (see developer manual). If the result set contains no data then the specified number is greater than the total number of rows available., default: 0, type: number
- `limit` — default: —, type: var
- `sort_column` — Field to order the result set by., default: secid, type: var
- `assetcode` — Filter by ticker codes. Only for the futures and options., default: —, type: var
- `sort_order` — Sort order. Can be 'asc' or 'desc'., default: asc, type: var
- `interim` — Show intermediate trading results (currency market only), default: 0, type: var
- `lang` — Language of the result set: ru or en, default: ru, type: var
- `numtrades` — Minimum number of trades with a security., default: 0, type: var
- `date` — Date to request information for. Format: YYYY-MM-DD., default: today, type: var
- `sort_order_desc` — (Deprecated) Sort order. Can be empty or set to 'DESC', default: —, type: var
