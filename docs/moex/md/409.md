# /iss/engines/[engine]/markets/[market]/boards/[board]/securities/[security]/candles

Get data for candlestick charts for the specified security on the specified board.

candles (GET)

HLOCV for candlestick charts

## Arguments

- `start` — Row number (the number of the first row is 0) to begin the result set with (see developer manual). If the result set contains no data then the specified number is greater than the total number of rows available., default: 0, type: var
- `till` — Interval end date Format: YYYY-MM-DD HH:MM:SS., default: 2037-12-31, type: var
- `from` — Interval start date Format: YYYY-MM-DD HH:MM:SS., default: —, type: var
- `interval` — Chart interval, default: 10, type: var
- `iss.reverse` — Change default sort order. Takes true/fale values., default: false, type: var
