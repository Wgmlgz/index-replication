# /iss/engines/[engine]/markets/[market]/boards/[board]

Get description of the specified board.
Example: https://iss.moex.com/iss/engines/stock/markets/shares/boards/TQBR.xml?lang=en

board (GET)

Board description

## Arguments

- `lang` — Language of the result set: ru or en, default: ru, type: var
