/iss/engines/[engine]/markets/[market]/boards/[board]/securities/[security]/orderbook

Get the best quotes for the specified security on the specified board.

orderbook (GET)
List of best quotes

Arguments

start

Row number (the number of the first row is 0) to begin the result set with (see developer manual).
If the result set contains no data then the specified number is greater than the total number of rows available.
Default: 0
Type: number

seqnum

(Deprecated) Update sequence number. Incremental parameter which can be used to request only updates.
Default:
Type: number

securities

Security filter. For example: securities=GAZP,AFLT,LKOH
Default:
Type: var

dataversion (GET)
Data version information.
