/iss/history/engines/[engine]/markets/[market]/boards/[board]/dates

Get dates for which history for the board is available.

dates (GET)
Date intervals available in the history.

Arguments

interim

Show intermediate trading dates (currency market only)
Default: 0
Type: var

tradingsession

Show data for required session (Stock market only)
  0 - Morning
  1 - Main
  2 - Evening
  3 - Total
Default:
Type: var
