/iss/engines/[engine]/markets/[market]/securities/[security]/candles

Get data for candlestick charts for the specified security.

candles (GET)
HLOCV for candlestick charts

Arguments

start

Row number (the number of the first row is 0) to begin the result set with (see developer manual).
If the result set contains no data then the specified number is greater than the total number of rows available.
Default: 0
Type: var

till

Interval end date
Format: YYYY-MM-DD HH:MM:SS.
Default: 2037-12-31
Type: var

from

Interval start date
Format: YYYY-MM-DD HH:MM:SS.
Default:
Type: var

interval

Chart interval
Default: 10
Type: var

iss.reverse

Change default sort order. Takes true/fale values.
Default: false
Type: var
