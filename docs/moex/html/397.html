/iss/engines/[engine]

Get description and availability time of a trading system.
Example: https://iss.moex.com/iss/engines/stock.xml

engine (GET)
General Trading System attributes

Arguments

lang

Language of the result set: ru or en
Default: ru
Type: var

timetable (GET)
Weekly Trading System schedule
dailytable (GET)
Trading system schedule besides the traditional weekly schedule - for example, for holidays and pre-holiday dates.
