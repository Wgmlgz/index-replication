/iss/securities/[security]

Get security specifications.
Example: https://iss.moex.com/iss/securities/IMOEX.xml?lang=en

description (GET)
Security description

Arguments

lang

Language of the result set: ru or en
Default: ru
Type: var

boards (GET)
Boards where a security is being traded

Arguments

lang

Language of the result set: ru or en
Default: ru
Type: var

primary_board


Default: 0

Type: var






start






Row number (the number of the first row is 0) to begin the result set with (see developer manual).
If the result set contains no data then the specified number is greater than the total number of rows available.

Default: 0

Type: number
