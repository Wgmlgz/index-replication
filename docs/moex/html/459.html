/iss/history/engines/[engine]/markets/[market]/boards/[board]/listing

Get security listing information for a given board

securities (GET)
Security listing details

Arguments

start

Row number (the number of the first row is 0) to begin the result set with (see developer manual).
If the result set contains no data then the specified number is greater than the total number of rows available.
Default: 0
Type: number

status

Trading status filter: traded, nottraded or all
Default: all
Type: var

lang

Language of the result set: ru or en
Default: ru
Type: var
